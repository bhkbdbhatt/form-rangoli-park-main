## 🙏 અમારા માન્ય સપોર્ટર્સને

<div align="center">

### 💛 આ પ્રોજેક્ટ તમારા જ પૈસાથી ચાલે છે.

**આપનું દરેક ટકારો એક નાગરિકને કાનૂની મદદ મળવાનું શક્ય બનાવે છે.**

</div>

તમે આ રીડમી વાંચી રહ્યા છો એટલે તમને આ પ્રોજેક્ટ વિશે કંઈક રસ છે. તમારો સમય, તમારું જ્ઞાન અને તમારા નાણાંનો ઉપયોગ — બધું જ મૂલ્યવાનું છે. ત્યારે ચાલો, આ પ્રોજેક્ટને વધુ મોટો અને વધુ અસરકારક બનાવીએ.

---

## 📌 આ પ્રોજેક્ટ શું છે?

**રંગોલી પાર્ક** એ ગુજરાત હાઉસીંગ બોર્ડના રસિદાવાળા મકાનમાં રહેતા ગ્રાહકો માટે બનાવવામાં આવેલું **ઓનલાઈન દરજાર ફરિયાદ ફોર્મ જનરેટર** છે.

આપણે અસંગત ઇલેક્ટ્રિક બિલ, વહેલાં વગેરે મુદ્દા ઉપર ગુજરાતના **ગ્રાહક તકરાર નિવારણ કમિશન** સમક્ષ ફરિયાદ કરવા માટે લોકોને અદ્યતન કાયદાની કાગળકામ કરવા માટે ઘણી મોટી અડચણો આવે છે — ભૂલ, ખોટું પ્રારૂપ, ગયું વહેલું ફરિયાદ, ગુણવત્તાની ચકાસણીનો ખર્ચ, અથવા કાનૂની મદદનું વધુ પડાણ.

**આ પ્રોજેક્ટ તે તકલીફ દૂર કરે છે — મફતમાં, ઘરબેઠા, ગુજરાતીમાં.**

| સમસ્યા | અમારો ઉપલ |
|---|---|

| અડધું ભરેલું ફોર્મ ફરી કાગળ કાઢવું પડે | આધાર કાર્ડ ચકાસણી સાથે ફોર્મ તરત સાચો દરજાબદ કરે છે |
| લાંબું ફોર્મ જંગલ વગેરે ભરવામાં થાક લાગે | ૪ સરળ તબક્કામાં વહેંચવામાં આવું, સ્પષ્ટ માર્ગદર્શન |
| ઈન્ટરનેટ છૂટાછવાયું હોય તો માહિતી જતાય | દરેક લખાણ આપોઆપ સાચવાય છે (Auto-Save) |
| કાનૂની કાગળ ડ્રાફ્ટ કરવામાં મોટો ખર્ચ | તરત જ પ્રિન્ટ-રેડી પીડીએફ તૈયાર |
| મોટા શહેરમાં ઓછામાં ઓછા કાનૂની વ્યવસાયીઓની નિર્ભરતા | સ્વતંત્ર, તટસ્થ અને મફત સાધન |

## ✨ મુખ્ય વૈશિષ્ટ્યો

- 📝 **૪-તબક્કાનું વ્યવસ્થિત ફોર્મ** — પ્રાથમિક ઓળખ, ફરિયાદીની વિગત, વિવાદ અને નાણાકીય માહિતી, અને તૈયાર દરજાર ફોર્મ
- ✅ **આધાર કાર્ડ ચકાસણી** — Verhoeff Checksum આધારિત ખોટો આધાર નંબર તરત પકડાય છે
- 💾 **આપોઆપ સાચવણી** — બ્રાઉઝર બંધ થઈ જાય તો પણ તમારી માહિતી સચવાય છે
- 📄 **એક ક્લિકે પીડીએફ** — કાનૂની દરજારનું પ્રિન્ટ-રેડી ડૉક્યુમેન્ટ તરત ડાઉનલોડ કરો
- 📧 **ઈમેલ દ્વારા મોકલવાની સુવિધા** — તરત ફરિયાદ સીધી સંબંધિત વિભાગને પહોંચાડો
- ♿ **સુધારાની તક** — વૃદ્ધાંગ અને દિવ્યાંગ લાભાર્થીઓ માટે સ્વતંત્ર તપાસ પ્રક્રિયાનો ઉલ્લેખ સ્વતંત્રરીતે ઉમેરાય છે
- 🏷️ **જાતિ-વર્ગ ટૅગો** — અનુસૂચિત જાતિ, અનુસૂચિત જનજાતિ, બક્ષીપંચ, અંધ જન વગેરેની છાંટ
- 🌐 **ગુજરાતી પ્રથમ** — સંપૂર્ણ અંતરફેરો ગુજરાતીમાં, તકનીકી જાણકાર વગર પણ સરળ
- 🔒 **ગોપનીયતા** — કોઈ સર્વર, કોઈ ટ્રેકિંગ, કોઈ જાહેરાત
